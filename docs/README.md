# Personal Agent Protocol Docs

> Source for the [Personal Agent Protocol SDK documentation](https://personal-agent-protocol.datalayer.tech), built with [Docusaurus](https://docusaurus.io).

```bash
# Install the dependencies.
make install
```

```bash
# Local Development: This command starts a local development server and opens up a browser window.
# Most changes are reflected live without having to restart the server.
echo open http://localhost:3000
make start
```

```bash
# Build: This command generates static content into the `build` directory
# and can be served using any static contents hosting service.
make build
```

The site documents only implemented SDK behavior as available. Planned PAP
surfaces are listed in the protocol status page until their conformance tests
pass.

```bash
# Publish if you have karma for.
make publish
```
