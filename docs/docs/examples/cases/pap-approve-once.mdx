# A Change, Approved Once

<CaseDeck id="pap-approve-once" />

Ada's jacket isn't warm enough. Manzanita doesn't exchange it yet: it returns an
operation, its exact terms. Her agent shows them to her, and sends the same
request again only with her approval of that revision. Ada is asked about every
operation, and nothing approves in her place.

- The wire, with new terms and a lost answer: the [Operations](/examples/operations) example flow.
- How to build it: the [Operations guide](/guides/operations/).
