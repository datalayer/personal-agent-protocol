# Your Application, a Company

<CaseDeck id="pap-your-application-a-company" />

The same protocol from the other side. A Maker publishes an application,
Exchange desk, and Sam's own agent, which the Maker has never heard of, uses it:
it asks signed out, Sam signs in on the application's page, and an exchange is
proposed in the Maker's own words, approved by Sam, and done once.

- How to build it: [Integrate a company](/guides/company/), and the SDK's reference company is built that way.
- A runnable one: the [company service example](https://github.com/datalayer/personal-agent-protocol/tree/main/examples/pydantic-ai/company-service).
