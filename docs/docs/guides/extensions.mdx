# Extensions

PAP extensions add optional wire capabilities. Reactor extensions add or
replace SDK implementation components. They complement one another but are not
the same abstraction.

## Negotiate a PAP extension

A company advertises support in its discovery document:

```json
{
  "extensions": {
    "operations": {
      "version": "2"
    }
  }
}
```

A personal agent advertises compatible extensions in its client metadata.
Protocol-defined extensions use plain names. Third-party names begin with a
domain controlled by their author, such as `example.com/gift-wrap`. Both sides
ignore unknown extensions and unknown fields.

## Negotiate in code

Both SDKs negotiate the same way: an extension is used only when the company
and the agent both list it, at the same major version, and this SDK
implements that version (`SUPPORTED_EXTENSIONS`: Operations version 2, Mediated
Sign-In version 1). An extension the company recognizes from the request itself, such
as Mediated Sign-In with its grant type, needs no entry on the agent's side, and a
company can't refuse it with `extension_required`.

```python
from personal_agent_protocol.extensions import negotiate_extensions
from personal_agent_protocol.models import ExtensionDescriptor

company = {
    "operations": ExtensionDescriptor(version="2"),
    "example.com/gift-wrap": ExtensionDescriptor(version="2"),
}
agent = {"operations": ExtensionDescriptor(version="2")}
assert negotiate_extensions(company, agent) == {"operations": "2"}
```

```typescript
import { negotiateExtensions } from '@datalayer/personal-agent-protocol';

const negotiated = negotiateExtensions(
  {
    operations: { version: '2' },
    'example.com/gift-wrap': { version: '2' },
  },
  { operations: { version: '2' } },
);
console.log(negotiated); // { operations: '2' }
```

The Operations behavior itself lives in `OperationsClient` (Python and
TypeScript), negotiated with `operations_negotiated()` / `operationsNegotiated()`;
see the [Operations guide](/guides/operations/). The SDK has no contribution
point for other extensions' behavior yet: a third-party extension is used by
the host's own code once negotiation says both sides list it.

Extensions cannot weaken mandatory protocol checks such as issuer binding,
secret redaction, Session JWT verification, replay protection, or exact operation
revision approval.
